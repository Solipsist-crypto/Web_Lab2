# Лабораторна робота: Верстка адаптивного макета інтернет-магазину (CSS Grid & Flexbox)

Цей проєкт є реалізацією адаптивного макета сторінки каталогу товарів інтернет-магазину з використанням сучасних можливостей CSS (Grid, Flexbox, BEM, CSS Variables) та базового JavaScript для фільтрації.

## 🛠 Технології та підходи

- **HTML5**: Семантична розмітка (`<header>`, `<nav>`, `<aside>`, `<main>`, `<footer>`).
- **CSS Grid**: Побудова основної структури сторінки за допомогою `grid-template-areas` та створення адаптивної сітки товарів через `repeat(auto-fill, minmax(...))`.
- **Flexbox**: Вирівнювання та позиціонування елементів у шапці, навігації та картках товарів.
- **Методологія BEM**: Іменування класів строго за структурою *Блок__Елемент--Модифікатор* для запобігання конфліктам стилів та уникнення глибокої вкладеності.
- **Mobile First**: Базові стилі розраховані на мобільні пристрої з подальшим розширенням під планшети та ПК за допомогою `@media (min-width: 768px)`.
- **CSS Variables (Design Tokens)**: Централізоване управління кольорами, відступами, шрифтами та радіусами закруглення.
- **Доступність та адаптивність**: 
  - Підтримка системної темної теми (`prefers-color-scheme: dark`).
  * Підтримка режиму зменшення руху (`prefers-reduced-motion: reduce`).
  * Анімація при наведенні тільки через продуктивні властивості `transform` та `opacity`.
- **JavaScript (ES6+)**: Філіграна інтерактивна фільтрація товарів за категоріями без перезавантаження сторінки.
