# Лабораторна робота №3: JavaScript (DOM, події, валідація, localStorage)

Цей проєкт є продовженням ЛР2. У цій роботі реалізовано динамічний каталог товарів з використанням чистого JavaScript (ES6+).

## 🛠 Технології та підходи
- **JavaScript (IIFE)**: Код розділено на модулі (`storage.js`, `render.js`, `events.js`, `main.js`), об'єднані в простір імен `window.App`.
- **DOM API**: Створення карток через `document.createElement` (безпечно, без `innerHTML` для даних).
- **Делегування подій**: Один обробник на сітку товарів для обробки кліків по кнопках.
- **Валідація форм**: Використання HTML5 API (`validity`, `setCustomValidity`).
- **LocalStorage**: Збереження стану кошика/каталогу з захистом від пошкодження даних (`try...catch`).
- **Фільтрація та пошук**: Реалізовано `debounce` для пошуку та сортування на копії масиву.
- **Строгий режим**: Всі скрипти виконуються в `"use strict"`.
